System 02 · Content AI Eval Loop · nightly + Friday digest

40+ AI tools, each one drift-prone.
This catches the drift before users do.

Content AI ships 40+ tools. Each one can quietly degrade as Claude / OpenAI / underlying models update, as user prompts shift, as edge cases compound. The classic failure mode: a tool got worse for 4 weeks, the WP forum noticed, then engineering scrambled. This system runs golden-set evals nightly, ranks regressions, surfaces them on Friday. The PM sees drift the day it starts, not when the forum notices.

How it runs

STACK
Golden set (200+ test prompts per Content AI tool) → nightly run via Claude/OpenAI → LLM-as-judge scoring against rubric → Postgres → Friday digest + Linear ticket auto-draft on regression.
REPLACES
Engineering manually testing Content AI tools after every model release. The "we shipped it, hope it still works" silent-failure mode.
ANCHOR METRIC
Time from "Content AI tool quality drift" to "PM visibility." Target same-day. Was 2-4 weeks (until WP forum complaints surfaced).

System 03 · The Build Kit · deliver with margin

An agency that rebuilds from zero every time
has no margin and no moat.

The Build Kit is a library of reusable, parameterized automation modules. Delivery stops being a from-scratch project and becomes assembly: pick the modules the signed scope needs, configure them to the client's stack, test against the client's data. Every engagement either reuses a module or contributes a new one back. The kit compounds, the margins follow it, and a moat forms quietly, because a competitor starting next month still has an empty kit.

How it runs

STACK
n8n holds the module library, each module parameterized to swap in a client's tools. Claude handles the configuration reasoning. The modules cover the real automations: leads, support, documents, reporting.
REPLACES
Rebuilding the same automation from scratch on every project. The linear cost curve where the tenth client costs as much to serve as the first.
ANCHOR METRIC
Build time per engagement, trending down with every project. Module reuse rate, trending up. Gross margin per build, following both.

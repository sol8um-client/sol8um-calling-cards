System 02 · AI Support Agent + Eval Loop · SaaS support case study

Auto-resolution that doesn't drift.
Quality holds because the eval loop holds it.

The standard failure mode of customer-support automation: ship the bot at 70% auto-resolution, celebrate, then watch the rate quietly drop to 45% over six months as the question mix shifts and nobody notices. This system replaces that with a Claude-powered support agent paired with a continuous eval suite: every change to the bot gets regression-tested against a golden set, drift gets caught before clients see it, and the handoff-resolution learning loop expands tier-1 coverage by ~3 issue types per month. Maps directly to your published 68% auto-resolution / $480K savings case study.

How it runs

STACK
Intercom / Front API → n8n + Claude classifier + handoff trigger → eval suite (golden set, regression test, drift monitor) → CI alert on quality drop.
REPLACES
The "we shipped a bot but it got worse over time" silent failure. Manual QA on a sample of tickets each month. The 3-month-late discovery that auto-resolution rate has halved.
ANCHOR METRIC
Auto-resolution rate stable month-over-month (target 68%, matching your published case study), no drift exceeding 3% before alert fires.

System 04 · Trust + Safety Ops · the system that lets you sleep at night

Some conversations
need to stop, not finish.

A mental-health-adjacent product running bilateral relationship conversations will see things you can't ship without preparing for. Hints of self-harm. Hints of abuse. Crisis-level emotional escalation. This is not a feature you add in month six. It's day-1 infrastructure. Claude flags. The conversation pauses with care, not silence. Both partners see help-resources immediately. A human queue picks up the case. The therapist-referral integration is built before you need it, not after.

How it runs

STACK
Claude classifier (crisis-detection) + Postgres flag queue + Slack alert (founder + on-call) + immediate in-product resource surface + therapist-referral integration via Spring Health or BetterHelp partner API.
REPLACES
The "we'll deal with that when it happens" approach that becomes a liability the moment it happens.
ANCHOR METRIC
Crisis-detection precision and recall on a curated test set (built before launch). Time-to-pause when flagged. Human-review SLA. Numbers tracked weekly.
